# weekend-free-data

토스 미니앱 **무료 주말 나들이**가 읽는 서울 무료 행사 데이터. GitHub Actions가 매일 05:10(KST) 서울시 문화행사 정보 API를 받아 `events.json`을 갱신한다.

- 원천: [서울시 문화행사 정보 (서울 열린데이터광장 OA-15486)](https://data.seoul.go.kr/dataList/OA-15486/S/1/datasetView.do) — 공공누리 1유형
- 포함 조건: 무료 · 아직 끝나지 않음 · 3주 안에 시작
- 앱이 읽는 주소: `https://raw.githubusercontent.com/qhshdlwl/weekend-free-data/main/events.json`
